# 3D 梦幻极光粒子圣诞树

用 Python（pygame + numpy）实现的实时 3D 粒子圣诞树动画，全部由程序生成，**无需任何外部图片或素材**。

## 效果

- **层叠圆锥树冠**：12 层参数化枝条，约 1.2 万个发光粒子，正弦抖动 + 末端下垂形成蓬松枝簇；双线性泼溅 + 加法混合，低分辨率渲染后升采样，得到柔和泛光。
- **三段式色彩渐变**：底部冰蓝 `#7dd3fc` → 中部紫 / 粉紫 `#c084fc` / `#f0abfc` → 顶部青白 `#ccfbf1`，并混入闪烁白色高光粒子。
- **暖金螺旋灯带**：树冠外围螺旋上升的暖金色 `#fde68a` 光点灯带，带灯珠节奏。
- **树顶金星**：多层径向光晕的暖金色五角星。
- **极光与夜空**：左侧蓝紫、右侧青绿的垂直条纹极光缓慢流动；地面铺满透视星尘；随机斜划的渐变拖尾流星。

## 交互

| 操作 | 效果 |
| --- | --- |
| 自动 | 圣诞树缓慢旋转 |
| 按住鼠标左键拖动 | 调整视角（松开后带惯性） |
| ESC | 退出 |

## 环境要求

- Python 3.9+
- pygame 2.6+
- numpy 1.24+

安装依赖：

```bash
pip install -r requirements.txt
```

## 运行

```bash
python christmas_tree_aurora.py
```

窗口尺寸 1280×800，内部按 0.60 比例渲染后平滑放大；实测约 40–50 FPS（视机器性能略有浮动）。

## 实现要点

- 世界坐标 → 绕 Y 轴（yaw）/ X 轴（pitch）旋转 → 透视投影。
- 粒子以 `(H, W, 3)` float32 缓冲做双线性加法泼溅（`np.add.at`），叠加低分辨率泛光层。
- 极光为低频正弦条纹场，每 4 帧更新一次后再叠加，兼顾质感与性能。
- 中文提示优先加载系统字体（微软雅黑 / 黑体 / 宋体），保证离线可用。
